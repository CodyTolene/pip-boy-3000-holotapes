# Runtime Assets

These files are installed through `metadata.json` under `HOLO/BRKBNCE/`.

- `APP.JS`: the small launch handoff; `MAIN.JS` and the remaining `*.JS`
  files are Espruino-pretokenized game pages and sprite data.
- `LEVELS.TXT`: 50 editable main-level layouts.
- `UI1.BIN`, `UI2.BIN`, `UI3.BIN`: 2bpp Pip-Boy UI/title artwork.
- `ABOUT.AVI`, `ABOUTC.AVI`: Clean and CRT-styled About screen videos.
- `*.WAV`: title, gameplay, game-over, and sound-effect audio.

`icon.png` and `preview.png` are repository metadata images; they are not
installed on the Pip-Boy.
