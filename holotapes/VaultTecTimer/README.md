# Vault-Tec Timer 2.0

A countdown timer with customizable alerts, and a stopwatch with lap function.

## Controls

| Input                                 | Action                                                         |
| ------------------------------------- | -------------------------------------------------------------- |
| Left scroll wheel (knob1) up/down     | Scrolls buttons and changes Timer time.                        |
| Right scroll wheel (knob2) left/right | Scrolls buttons.                                               |
| Left scroll wheel press               | Selects hovered over button.                                   |

## Alert Types

- **SOUND ONLY** — Choose a sound from the ALARM folder, default is Klaxon
- **LED TORCH** — Flashes LED on and off repeatedly
