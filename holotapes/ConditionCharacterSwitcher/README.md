### Description

Replaces the graphic on the stock Pip-Boy 3000 Condition (STAT > CND) screen
with a custom character. Ships with two animated characters, Mk V Vault-Boy and
Vault-Girl, and picks up any additional characters in the `chars` folder. Custom
static characters can be created with the
[character editor web tool](https://aidanslab.github.io/ConditionCharacterEditor/).

Launch the holotape to open a scrollable character list. Highlighting an entry
shows a preview on the right. Selecting "None" reverts the Condition screen to
the stock Vault-Boy graphic.

### Controls

| Input                     | Action                           |
| ------------------------- | -------------------------------- |
| Left scroll wheel (knob1) | Move the cursor up/down the list |
| Left scroll wheel press   | Select the hovered entry         |
