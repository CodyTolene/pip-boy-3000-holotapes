# Signal Match

## Info

**Author:**

- [@Radiomaru7](https://github.com/Radiomaru7)

## Description

A Simon Says-style memory game for the Pip-Boy 3000. Numbers light up one by one
on a Vault-Tec dial; tune back to each of them in the same order. Every round
adds one more number to the signal. Your best number of rounds matched is saved.

The menu and the SIGNAL LOST card show Vault Boy art read from the Pip-Boy's own
DATA files (Perception and Computer Whiz). Your best also shows in STATS >
GENERAL as Signal Match Best Rounds.

### Controls

| Screen   | Control          | Action                           |
| -------- | ---------------- | -------------------------------- |
| Menu     | Either wheel     | Move up and down the list        |
| Menu     | Press left wheel | Start, or open the controls page |
| Controls | Press left wheel | Back to the menu                 |
| Playing  | Either wheel     | Turn the dial to a number        |
| Playing  | Press left wheel | Send the number the dial is on   |
| Playing  | Hold left wheel  | Back to the menu (rounds count)  |
| Lost     | Press left wheel | Back to the menu                 |

The dial is a single ring, so either wheel turns it. The same table is on the
CONTROLS page in the holotape's menu.

### How to Play

1. Choose START. The line above the dial says WATCH THE PATTERN while the
   numbers light up.
2. When it says YOUR TURN: 1 OF n, turn either wheel to the first number and
   press the left wheel to send it. Do the same for each number in order.
3. Send the whole signal right and a new round starts with one more number.
4. One wrong number and the signal is lost: the card shows what you sent, what
   the signal was and how many rounds you matched.
